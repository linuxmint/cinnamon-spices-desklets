# Screen Time Desklet

Shows today's **active** screen time on your desktop (e.g. `3h 42m`).

Counting automatically pauses when you're idle (no mouse/keyboard input) and
the counter resets at midnight.

## Settings

Right-click the desklet → **Configure...**

- **Idle threshold** — seconds of no input before counting pauses (default 60s)
- **Show seconds** — include seconds in the display
- **Font size** — size of the text
