# Vinyl Record Player Desklet

A vinyl record player desklet for the Cinnamon desktop.

## Features

- Spinning vinyl record on your desktop
- Play / Pause toggle
- Adjustable speed (33 RPM / 45 RPM)
- Time display showing elapsed play time
- Click the record to toggle play/pause

## Installation

1. Download and extract to `~/.local/share/cinnamon/desklets/`
2. Or install via Cinnamon System Settings → Desklets

## Usage

Right-click the desklet to access settings. Use the popup menu to play/pause or change speed.
