# Workspace Indicator Desklet

This desklet displays the number of the active workspace on the desktop, optionally also showing the total number of workspaces.

On `right-click`, while controls are displayed, you can drag the indicator to your desired location on the desktop. 

## Options

- font and size;
- foreground colour and opacity;
- background colour with opacity (choose “Custom `+`” from the colour-picker to set opacity);
- toggle workspace total on/off.
