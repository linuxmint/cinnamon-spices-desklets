# Tracker

A Cinnamon desklet for tracking tasks with due dates.

- Tasks grouped by title and sorted by due date.
- Relative labels: Today, Tomorrow, In N days, N days overdue.
- Built-in editor with calendar, edit mode and delete confirmation.
- Terminal-style themes, typography and layout options.
- English and Spanish; follows the system language, or pick one in the
  desklet settings.

## Install

From Cinnamon Spices, or copy this folder to
`~/.local/share/cinnamon/desklets/tracker@sms-5` and add the desklet.

## Translations

`po/` contains the gettext template and the Spanish translation. Run
`cinnamon-xlet-makepot -i .` to compile them locally.
