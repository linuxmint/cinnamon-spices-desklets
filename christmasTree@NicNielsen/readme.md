# System Resource Monitor

A clean, minimal desklet showing a character based retro Christmas tree with blinking lights.

![Screenshot](screenshot.png)

## Features

- **Change size**: Allows you to change the size of the desklet
- **Change star colour**: Allows you to change the colour of the star on top of the tree
- **Change blinking speed**: Allows you to change how fast the lights blink

## Requirements

This desklet relies on standard system libraries, but ensure you have `glib` and `gtop` bindings available (installed by default on most Linux Mint installations).

## Settings

Right-click the desklet on your desktop and select **Configure** to access:
- Change Size
- Change Transparency
- Change light blinking speed
