1. The idea and the first fence

A fence is an area on the desktop that shows the content of one folder: applications (.desktop files), documents and subfolders. The folder is the source – whatever is in it appears in the fence; whatever is deleted there disappears.

You start with one fence. It shows the still empty folder default in the shared base directory (default ~/.local/share/avincelaunch). Each fence has its own link subdirectory inside it.

More fences can be added in three ways:

  • Right-click → Starter layout… (also in the quick start) – nine fences with a title (Internet, Communication, Office, Graphics & Photos, Multimedia, Games, Development, Tools, System) in a 3 × 3 grid. Your installed applications are suggested by their category: untick them in the preview or assign them to another fence, then Create. Each application is placed as a copy of its .desktop file in the new folders; Cinnamon's settings pages are not suggested. An empty fence without a name that you start from becomes the first one. To undo: Remove starter layout… – the fences go, their folders are moved to ~/.config/avincelaunch/backups/startaufstellung-….
  • Right-click → Duplicate fence – same look and size, but a folder of its own, still empty (a folder portal keeps the same folder). The copy appears at the next free spot beside the original – if there is none, slightly offset on top of it –, is unlocked and can be dragged to its place right away.
  • System Settings → Desklets: select aVinceLaunch and click + at the bottom.

A fence's name and folder are set in Configure… → General. Without a name of its own a fence is called like its folder.

2. Content and order

  • Copy files, application launchers or folders into the link folder – quickest via right-click → Open link folder.
  • Or in Configure… → Items: add and edit entries, change the order, then apply.

The fence updates by itself as soon as the folder changes.

Configure… → General → Order in the fence sets the order:

Manual (Items list)as the list on the Items page shows it (default)
Name A–Z / Name Z–Aalphabetical
Typefolders, then programs, then documents
Date modifiedmost recently changed first
Recently addednewest entries first

A pinned entry (see item menu) always stays at the front, whatever the order. If an entry is missing for a while – for example while a program is being reinstalled – it keeps its place in the list for 30 days.

3. Launching and folders

  • A click starts an application or opens a document. Configure… → General → Launch mode: single or double click.
  • Folders open inside the fence; Home takes you back. Folder click action can open the file manager instead.
  • When the mouse rests on a tile for a moment, a tooltip shows the full name and, below it, the description or path.

4. The item menu

A right-click on an item shows its name at the top of the context menu, followed by these entries:

Move to ▸into another fence with a folder of its own (portals and fences with locked content are no target)
Pin to the front / Unpinthe entry always stays at the front, whatever the order; a pin shows it
Remove from fence…after a confirmation into the trash – it can be restored from there

After a move, every fence's context menu shows Undo: “…” to …; the notification at the screen edge has the same button. Only the last move can be undone.

When the content is locked (Lock ▸ Content), these entries are greyed out.

5. Folder portal (view only)

Instead of a link group, a fence can show any existing folder, for example ~/Downloads: Configure… → General → Link storage → Source: Folder portal (view only), then pick the folder with Choose….

  • A portal is a view only: open files, start applications, go into subfolders. aVinceLaunch never adds, changes or deletes anything in the folder – not even a helper file of its own.
  • Exception, the base directory: if a portal shows a folder that contains the aVinceLaunch base directory (for example your home folder ~), the base directory and its groups stay writable – the link-group fences keep working there as usual. The dialog points this out when such a folder is chosen.
  • The portal folder is protected under its own path. A symbolic link to it from elsewhere is not followed: if, say, a group folder really points to the portal folder, aVinceLaunch writes through that link as into any group.
  • It is always sorted automatically (setting “Automatic folder sort”); the Items page only shows a note for portals.
  • At most 200 entries; below them a note leads to the rest in the file manager.
  • Hidden files can be shown.
  • On the NAS (or another network drive) aVinceLaunch looks for changes itself every 30 seconds – only while the fence is visible, in the background. If the NAS cannot be reached, the fence says so and tries again every minute. If it does not answer at all (reading hangs), the fence shows “not reachable” after 2 minutes and tries exactly once more; if that hangs too, it waits until the NAS answers again.

6. Title row, collapsing, search

New fences show their title row (☰, name, arrow) while the pointer is over them. When it is turned off, a locked fence only shows its name floating above it while the pointer is there. Turn it on or off in Configure… → General → Title → Show title row or for all fences at once with right-click → Show titles of all fences (or Hide titles of all fences).

Title row position:

  • Inside the fence – only under the pointer (default)
  • Inside the fence – always
  • Above the fence – as a tab under the pointer

The ☰ button on the left of the title row opens the context menu. An unlocked fence always shows its title row – it is then the handle for moving.

Collapsing: with the arrow in the title row or right-click → Collapse fence. Only the title row remains; the space below stays free so that nothing gets covered when the fence opens again. Expand it with the arrow, a double click on the bar or the menu. With Expand on hover when collapsed a collapsed fence opens while the pointer is over it.

Search: right-click → Search all fences… opens a search field. While you type, all fences show only the entries whose name matches (collapsed fences stay closed). A click on a match starts it, Enter starts the first one – row by row from the top left. Esc or a click elsewhere closes the search. If you like, a magnifier in the title row does the same (Configure… → General → Search button in the title row).

7. Moving and locking

New fences are locked – nothing moves by accident. The submenu right-click → Lock ▸ has three switches:

Positionmoving off or on
Sizeresizing off or on; the dialog also offers “Like the position” (default)
Contentno moving, removing or pinning from the item menu, and the fence accepts no items from other fences or the desktop; the Items page stays available

To move a fence:

  1. Turn off right-click → Lock ▸ Position. The menu then shows the red hint Resize: drag an edge or the corner.
  2. Drag the fence by its title row.
  3. Turn Lock ▸ Position back on.

The position can also be typed in as numbers in Configure… → Layout → Position (aligned to the desklet grid if you like).

8. Resizing

With the size unlocked, drag the right edge, the bottom edge or the bottom-right corner. An outline shows the new size; it is saved when you release the mouse. Esc cancels.

  • Restore previous size undoes the last change – even when the fence is locked.
  • Restore original size returns to the size before the first change.

9. Snapping and guides

While moving and resizing, a fence snaps to its neighbours: edges aligned, same width or height, the same gaps as between the other fences. Green guide lines show what it aligns to. Screen edges keep a minimum margin, and fences do not slide over each other. Other desklets (e.g. aVincePulse) count as obstacles and are never moved.

Hold Ctrl to drag freely: no snapping, no grid, no overlap protection – only the screen edges remain. The fence then shows FREE (Ctrl). A fence placed this way stays exactly there after a restart, too.

Limit: when the desklet grid is switched on or changed in System Settings, Cinnamon itself aligns all desklets to it – freely placed fences then move into the grid on the next start.

10. Arrangement, history, aligning

Right-click → Restore arrangement ▸ lists the last three changes to position and size of all fences, with time and a symbol for the kind of change (moved, width, height, …). Changes within one minute count as one. The Original arrangement is always at the top. Restoring is recorded in the history too, so it can be undone.

Align all fences puts slightly misplaced fences back into rows and columns. What counts is where the majority stands; the gaps are learned on the first start. Fences moved far away stay where they are, and nothing gets covered.

13. The Configure dialog

Generallink storage (source: link group or folder portal, link or portal folder), title (name, title row, position, alignment), behaviour (launch mode, folder click action, expand on hover, search button), sorting, tooltips, “For all fences” (shared base directory)
Appearancecolour mode, presets, border, font and shadow, all colours
Layoutgrid (columns, icon size, spacing), size and content fit, position
Behaviourlock: position, size, content
Itemsedit entries and subfolders, order

A new shared base directory applies at once: the link-group fences show the new folder, and sorting in new applications uses it too, without a restart. Portals keep showing their own folder.

Base directory on a NAS (or another network drive): the link-group fences then read their folders in the background, like a portal, so a NAS that hangs never stops the desktop. Changes are picked up every 30 seconds while a fence is visible; if the NAS cannot be reached, the fence says so – if reading hangs, “not reachable” after 2 minutes – and tries again every minute. What you start yourself – Configure…, the item menu – still reads the folder directly; if the NAS hangs at that very moment, that one action waits for it.

14. Backing up and transferring

In Configure… the ☰ menu at the top right offers Export to a file and Import from a file – each for the fence currently selected.

An import replaces all settings of the fence – including folder, name, size and position. Before importing, check which state the file comes from; the file name alone does not tell.

In addition, aVinceLaunch backs up the settings of every fence by itself – on each start, when Configure… opens and before removing, but only when something has changed. ~/.config/avincelaunch/backups/einstellungen-<number>/ holds the last five states plus the newest one older than a day; the file name is the date and time. The folder of a removed fence is deleted 30 days after removal.

To bring back a saved state: Configure… → ☰ → Import from a file and pick a file from the folder above. The .config folder is hidden: press Ctrl+H in the file dialog or type the path with Ctrl+L. The warning above applies – the import replaces all settings of the fence currently selected. If the file dialog stops responding after Open, close Configure and open it again – nothing has been changed up to then. What went wrong is written to ~/.cache/avincelaunch/einrichten-<number>.log (new each time it opens) – include this file in a bug report.

The content itself lives as files in the base directory and can be backed up like any other folder.

15. Caution

“Reset to defaults” (☰ in Configure) resets everything: folder, name, size and position. For the look alone there is Reset appearance….

The “–” button in System Settings → Desklets removes all aVinceLaunch fences at once; Cinnamon deletes their settings. To remove a single fence, right-click a free spot in the fence or its title row → Remove this fence…. The confirmation names the fence; clicking with Ctrl held skips it. When the right-click hits an item the entry is not in the menu – but the narrow gap between two items counts as a free spot.

After removing a fence its folder and all files in it are kept – it is just not shown anywhere any more, and “Move to” no longer offers it. To see it again, add a fence (e.g. Duplicate fence) and pick the old folder in Configure… → General → Link storage. Duplicates, too, leave their own folder behind when removed.

Removed by mistake? Cinnamon deletes the fence's settings; the backup is kept for 30 days (see Backing up). To bring the fence back:

  1. In another fence choose Duplicate fence.
  2. In the new fence open Configure… → ☰ → Import from a file and pick the newest file in ~/.config/avincelaunch/backups/einstellungen-<number>/ of the removed fence. The confirmation on removing names the number.
  3. The fence takes over folder, name, look, size and position – it is back where it was.

16. Add-on package (optional)

A few things a desklet cannot do by itself. For them there are the aVinceLaunch helpers, a separate download (GitHub release page, aVinceLaunch-Helfer-0.1.0.tar.gz) – they are not part of the package from Cinnamon Spices:

  • Program watcher – asks for every newly installed program or web app which fence it should go into, usually with a suggestion.
  • Super+Shift+D – “desktop free”: all fences and the desktop icons off, press again to bring them back. The state stays after a restart, until the next press. Works on X11 and Wayland.
  • Move to a fence… – right-click a launcher on the desktop.
  • Double-click on the free desktop – like Super+Shift+D, X11 only and only if switched on at installation. It listens to mouse buttons only.

Install with ./install.sh from the unpacked package – only into your own folders, with a backup of everything it replaces; remove with ~/.local/share/avincelaunch-helfer/uninstall.sh. Details are in the package's README.md.
